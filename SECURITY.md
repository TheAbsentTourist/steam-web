# Security

Report vulnerabilities to chucktastictime@gmail.com or via GitHub issues: https://github.com/TheAbsentTourist/steam-web/issues

Do **not** include a Steam Web API key, SteamID, or `config.json` in a report. Rotate a leaked key at https://steamcommunity.com/dev/apikey.

The plugin does not host user data. Credentials stay on the installer machine.
